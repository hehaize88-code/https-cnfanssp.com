# Superbuy Returns and Refunds: A Warehouse Checklist

A Superbuy return starts with the order stage, the seller's applicable conditions and clear evidence of the problem. A cancellation before purchase, a return from the warehouse and an issue after international delivery are different processes. This guide explains how to prepare a useful request and track its outcome without assuming that every product has the same return window or refund destination.

## Identify the stage before choosing an action

Open the order and copy the status exactly as displayed. Check whether the agent has purchased the item, whether the seller has dispatched it, whether the warehouse has stored it and whether it has entered an international parcel. The correct next step depends on these facts. A cancellation request made before purchase does not establish the conditions for returning an already purchased item.

Create a short private record with the order identifier, selected option, amount paid, current stage and desired resolution. If a parcel has already been submitted, include its identifier and ask whether the item can still be held. Do not assume a request message stops warehouse processing. Wait for confirmation before treating the item as removed from a parcel or the transaction as cancelled.

## Preserve the purchase specification

A return request is easier to assess when the intended purchase is unambiguous. Save the selected size, colour, version, quantity and included pieces, together with the relevant listing information available at purchase. Keep the original option text where possible. Several translated options may look alike even though the seller uses them for different versions or bundles.

Compare that record with the order actually placed. If the submitted option was wrong, say so accurately rather than describing it as seller error. If the warehouse item differs from the authorised order, identify the exact difference. This distinction matters for the discussion of eligibility and costs. The goal is a request that another person can understand without reconstructing your intentions from a general product photograph.

## Review warehouse evidence promptly

Start with identity and quantity before evaluating cosmetic details. Match the model, selected option, size label and included pieces. Then inspect visible damage, construction and measurements relevant to your decision. Use photographs attached to your own warehouse item; another buyer's images cannot prove the condition of yours. A missing view is a reason to clarify the evidence, not proof of a defect.

Record when the stored-item record became available and when you reviewed it. Storage time and the seller's after-sales window are separate clocks. A free storage allowance does not mean you can delay a return decision for the same period. If the evidence raises a material issue, ask about the applicable deadline immediately and keep the item out of an international parcel while the matter is unresolved.

## Request one missing fact at a time

A useful clarification request names the item, the exact area and the decision the answer will support. For example, ask for a ruler view of the garment's chest width laid flat, or a close view of the reported damage next to the item label. Avoid a broad request to check whether something is good. The warehouse needs an observable question, and you need evidence that can change your decision.

Keep measurements comparable. If your reference garment was measured flat from seam to seam, explain that method rather than comparing it with a circumference measurement. For a set, list the components you expect. A more precise evidence request can prevent unnecessary return costs, but it should not become an excuse to let an applicable deadline pass. Ask support how an open clarification affects the available after-sales action.

## Write a factual return request

Use a short structure: order identifier, authorised specification, observed difference, evidence reference and requested outcome. An illustrative message might say that the order specifies size L while the warehouse label shows M, and ask whether a return for refund is available before parcel submission. This is a template for organising facts, not a claim that a particular order qualifies.

Attach only relevant evidence through the official account process and keep personal payment or address details private. Ask whether the seller has accepted the request, what should happen to the item and which cost items apply. Avoid submitting several conflicting requests for the same order. If new evidence changes your preferred outcome, update the existing conversation and make the revised request explicit.

## Separate refund eligibility from return costs

Even when a return is accepted, the net refund can differ from the product price. Ask how Chinese return delivery, any original domestic freight, already completed optional services and other stated charges will be handled. Do not assume they are all refundable or all excluded. Record the answer for the specific order and compare it with the actual transaction later.

A practical decision table has the expected product refund, any confirmed deductions, return delivery and the alternative cost of keeping the item. Use known amounts and label unknowns clearly. Do not invent a fixed Superbuy return fee or universal percentage from another customer's screenshot. The live seller terms, applicable service conditions and confirmed request govern the case you are deciding.

## Understand why some orders need special care

Customised products, wholesale quantities, restricted goods and orders with unusual seller conditions should be reviewed before purchase. A general retail expectation may not apply. Superbuy's public guidance distinguishes some marketplace and service paths, including 1688 and forwarding. Confirm which process your order used instead of transferring the conditions from a different kind of purchase.

For forwarding, you purchased the product yourself and the warehouse receives it on your behalf. That changes who holds the seller relationship and which inspection service was selected. For a multi-unit order, establish whether the evidence concerns one item, a sample or the whole batch. A single photograph should not be described as an inspection of every unit unless that is what the service actually performed.

## Keep the physical item eligible for the agreed action

Do not request tag removal, original-box disposal or another irreversible modification while a return question is open. Such changes can remove evidence or conflict with seller requirements. Keep the product, labels and accessories together until the authorised process is clear. If a change has already occurred, disclose it so that support can evaluate the actual condition.

Likewise, do not include the disputed item in a parcel while assuming the discussion will resolve itself. International dispatch can make a seller return substantially more complicated. The relevant checkpoint is confirmation that the item is held or excluded, not simply the fact that you sent a message. Record that confirmation and verify the selected contents again before paying for the parcel.

## Track the refund as a series of events

Keep separate dates for the request, acceptance, return dispatch if required, seller receipt, refund approval and the actual account credit or payment reversal. These events may occur at different times. A status saying refund processing is not evidence that the funds have arrived. Use the transaction record to close the financial part of the case.

Check the refund destination rather than assuming it will return directly to the original card. If money is credited to a platform balance, any later withdrawal or payment reversal is a separate matter governed by its current process. Compare the amount and currency with the confirmed resolution, including documented deductions. If there is a discrepancy, reference the existing case and the specific missing transaction instead of starting the explanation again.

## Use a different evidence set after international delivery

If the item has already arrived overseas, preserve photographs of the outside package, labels, internal protection and the item before discarding anything. A seller mismatch, packing damage, carrier damage and a missing component require different evidence. Review the applicable after-sales or insurance process promptly, including its submission deadline, rather than assuming warehouse-return instructions still apply.

For future orders, use the warehouse checkpoint to resolve identity, measurements and visible defects before dispatch. Keep a short record of the outcome: what was wrong, which evidence helped, which costs applied and what you would check earlier next time. This turns one return into a more reliable purchasing routine while keeping claims specific to the actual order.
