A spreadsheet row promises a black zip hoodie in medium. Its button opens a maintenance notice. Before you discard the find, check which address failed. The button, the agent's product preview and the seller's listing are three different places. This checklist helps you recover a usable source link, identify a missing option and decide when to retire a row.

Keep the original before trying a fix

Copy the address behind the button into a private note. Keep the spreadsheet row number, product label, intended size or model and the date you opened it. If tapping the image only enlarges a thumbnail, look for the product name, link column or explicit seller link. In a sheet, the words displayed in a cell can differ from its hyperlink. Copying the words “open item” into a product search loses the destination.

Keep two fields in your note, one for the address you received and one for the final address the browser shows. This preserves the evidence when a short link redirects or a shop replaces its listing. Before sharing your findings, remove account, cart, invitation and tracking details. A public product identifier and a description of the result are usually enough to explain the problem.

Find the first point that fails

Open the saved link and read the domain in the address bar. Did it take you to a directory, an agent page or the original marketplace? Look at the page body as well. A normal-looking page can contain a removal notice followed by recommendations from the same shop. Those suggestions can look remarkably like the item you wanted, especially on a small screen.

Recognise the marketplace identifier

These common desktop address patterns show where to look. The word NUMBER represents the listing's actual digits. The patterns are illustrations rather than shopping links. Prefer the address obtained from the seller's product page, especially when a mobile share link uses a different format.

Marketplace Example pattern Part to keep
Weidian weidian.com/item.html?itemID=NUMBER The digits after itemID=
Taobao item.taobao.com/item.htm?id=NUMBER The digits after the listing's id=
1688 detail.1688.com/offer/NUMBER.html The offer number before .html

A number by itself has little value without the marketplace name. The number printed after a size option can be a variant identifier. A shop number identifies a shop. Neither reliably reconstructs a product page. Preserve the original link intact until you have seen the destination and matched the item. Recover an address copied from a phone or spreadsheet

A phone share message may contain a title, promotional text, a short URL and an instruction to open an app. Start with the actual link, including the full text up to its end. When a sentence wraps onto a new line, check whether the spreadsheet copied only the first part. An address ending in id= gives the parser a field name but no product number. Return to the original cell or share action for a fresh copy rather than filling in the missing digits from memory.

Sometimes the agent address wraps a marketplace address inside a parameter. Characters such as %3A and %2F can represent punctuation within the embedded URL. Preserve that encoding when copying the complete outer link. If the page offers an original-product link, follow that link and copy the browser address after it opens. Editing characters or stripping everything after a question mark can remove the item number along with the tracking information.

If an invite or sign-in screen is the final page you can see, stop there and record the access requirement. Enter an account through the marketplace's own app or known domain if you normally use one. A link checker cannot establish current stock from a sign-in screen. Avoid pasting payment, order-history or account-session links into public converters when all you need is the public listing.

Distinguish a lost option from a lost listing

After the source opens, match the shop, item type and actual selected option against the row. Read the option text after selecting it. A hoodie listing might combine a pullover, a zip version and matching trousers under one gallery. The first photograph or lowest price may represent a different selection. Use the displayed price and quantity only after the correct options are selected, and date the observation.

Suppose the row says “black zip hoodie, M” and the saved marketplace number matches. On the seller page, black is available in L, while M can only be selected in grey. Record “black/M unavailable on this check.” The product link is useful for someone considering the other options. Keeping the row as an exact match, or marking the whole shop dead, would both mislead the next reader.

A second example has a different outcome. Suppose the same thumbnail appears at a new address, with a different shop name and a new item number. Create a separate candidate. Check its size chart, option photos, quantity and description before treating it as a replacement. An identical photograph cannot establish that the seller, material or sizing is the same. Handle existing orders separately

Someone with a paid order has a different question from someone browsing finds. If a saved item disappears after payment, open the records you already hold. Identify the order reference, amount and date, the selected variant, and the last event that was actually confirmed. A seller dispatch notice, warehouse intake and carrier acceptance each describe a different stage. The old shopping link cannot tell you which one occurred.

If the parcel has a carrier tracking number, use the carrier named on the dispatch record to check the latest scan. For an order that has no confirmed dispatch, use the support contact on the official maintenance notice. Include one order reference and one precise request, such as asking whether the item was purchased from the seller. Keep receipts private and redact unrelated details. A new link is useful for research, but repeating payment introduces a second transaction. Maintenance and order checks

Leave a decision the next reader can use

Write one dated sentence with the marketplace, public item number, result and next action. “Weidian source opens; black/M unavailable; check the seller options again before shortlisting” distinguishes the limitation from a broken destination. If the directory opens a shop with no recoverable item ID, mark it unresolved and ask the person who shared the row for an original product link. If the seller explicitly removed the listing, archive it and verify any replacement from the beginning.

Keep verified rows and unresolved ones separate. A small, accurately described shortlist saves more time than repeated attempts to open the same uncertain link. When you revisit a row, update the observation and date together. That way the next person can see exactly what was checked and decide whether it still answers their question.
